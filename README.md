# پنل مدیریت انبار و محصولات

این پروژه یک پنل ادمین ساده و کاربردی برای مدیریت موجودی و قیمت کالاهاست. رابط کاربری بر اساس API آماده‌شده طراحی شده و برای استفاده شخصی در فروشگاه اینترنتی یا انبار به‌کار می‌رود.

## ویژگی‌ها

- ورود و ثبت‌نام با JWT
- جست‌وجو در نام کالا
- صفحه‌بندی سمت سرور
- افزودن، ویرایش و حذف محصول
- رابط واکنش‌گرا برای صفحه‌های کوچک و بزرگ
- مدیریت نام‌کاربری و توکن نشست در مرورگر

## تکنولوژی‌ها

- React
- Vite
- Lucide React

## راه‌اندازی

1. API را اجرا کنید:

   ```bash
   cd _api-inspect/warehouse-api
   npm install
   npm start
   ```

2. در ترمینال دیگری، پروژه فرانت‌اند را اجرا کنید:

   ```bash
   cd /Users/maryamamroodi/Downloads/week19
   npm install
   npm run dev
   ```

3. مرورگر را باز کنید و به آدرس زیر بروید:

   ```text
   http://localhost:5173
   ```

4. اگر API روی پورت دیگری اجرا می‌شود، متغیر محیطی زیر را تنظیم کنید:

   ```bash
   export VITE_API_URL=http://localhost:3000
   ```

## حساب‌های نمونه

- نام کاربری پیش‌فرض API: `milad`
- برای ورود، از همان نام‌کاربری و رمز عبور استفاده کنید یا یک حساب جدید ثبت کنید.

## ساختار پروژه

- `src/` : کد فرانت‌اند
- `public/` : فایل‌های ثابت و تصویر‌های عمومی
- `_api-inspect/warehouse-api/` : API نمونه و دیتای انبار

## نکته

این پروژه برای تمرین و پیاده‌سازی یک پنل مدیریتی شخصی ساخته شده و به‌صورت واقعی برای کاربری روزمره در یک کسب‌وکار کوچک قابل توسعه است.
