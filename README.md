# پنل مدیریت و فروشگاه شخصی

این پروژه شامل دو بخش اصلی است:

- پنل مدیریت کالا برای اداره موجودی و قیمت محصولات
- فروشگاه آنلاین ساده برای نمایش محصولات به مشتریان

رابط کاربری بر اساس API آماده‌شده طراحی شده و برای استفاده در یک کسب‌وکار کوچک مناسب است.

## ویژگی‌ها

- ورود و ثبت‌نام با JWT
- جست‌وجو در نام کالا
- صفحه‌بندی محصولات
- افزودن، ویرایش و حذف محصول از پنل ادمین
- فروشگاه عمومی برای نمایش محصولات
- رابط واکنش‌گرا برای موبایل و دس‌تاپ
- مدیریت توکن ورود در مرورگر

## تکنولوژی‌ها

- React
- Vite
- Lucide React

## راه‌اندازی

1. API را اجرا کنید:

   ```bash
   cd _api-inspect/warehouse-api
   npm install
   npm start
   ```

2. در ترمینال دیگری، پروژه فرانت‌اند را اجرا کنید:

   ```bash
   cd week19
   npm install
   npm run dev
   ```

3. مرورگر را باز کنید:

   ```text
   http://localhost:5173
   ```

4. اگر API روی پورت دیگری اجرا می‌شود، متغیر محیطی زیر را تنظیم کنید:

   ```bash
   export VITE_API_URL=http://localhost:3000
   ```

## حساب‌های نمونه

- نام کاربری پیش‌فرض API: `milad`
- برای ورود به پنل مدیریت، از همان نام‌کاربری و رمز عبور استفاده کنید، یا یک حساب جدید ثبت کنید.

## ساختار پروژه

- `src/` : کد فرانت‌اند
- `public/` : فایل‌های ثابت و لوگو
- `_api-inspect/warehouse-api/` : API نمونه و دیتای محصولات

## نکته

این پروژه برای تمرین، توسعه شخصی و راه‌اندازی یک فروشگاه کوچک با پنل مدیریت واقعی طراحی شده است و می‌تواند به‌راحتی برای کسب‌وکاری شخصی توسعه پیدا کند.
